How to Add Menu and Submenu Items

This guide explains how to modify the application to include new navigation items and their corresponding content.

File Structure Overview

The key files you'll be working with are:

  • app-data.js: Defines the structure of the navigation menu in the menuItems constant and provides fallback content.
  • content/: This directory is where the markdown files (.md) for each page's content should be stored.
  • icons.js: Contains the SVG icons used in the menu.

How to Add a New Submenu Item

Let's say you want to add a new topic called "Rhythm" under the "Music Theory" category.

Step 1: Edit app-data.js

  1. Open the app-data.js file.
  2. Find the menuItems array.
  3. Locate the object for "Music Theory" (it has id: 'theory').
  4. Add a new object to its children array.

Example:

// ... inside the 'theory' object's children array
{
  id: 'theory-rhythm',
  label: 'Rhythm',
  icon: MusicIcon,
  contentPath: '/content/theory/rhythm.md'
}
  • id: A unique identifier for the item. The convention is parent-id-item-name.
  • label: The text that will be displayed in the menu.
  • icon: The icon to display. You can reuse existing icons like MusicIcon or FolderIcon from icons.js.
  • contentPath: The path to the markdown file that holds this item's content.

Step 2: Create the Content File

  1. Create a new file at the exact path you specified in contentPath. In this case, you would create content/theory/rhythm.md.
  2. Add your markdown content to this new file.

Example content/theory/rhythm.md:

# Rhythm

Rhythm is music's pattern in time. Whatever other elements a given piece of music may have (e.g., patterns of pitch or timbre), rhythm is the one indispensable element of all music.

(Optional) Step 3: Add Fallback Content

If the application can't fetch the file from the server (e.g., during local development without a server), it will use the fallback content from app-data.js.

  1. Open app-data.js.
  2. Add a new entry to the contentMap object that matches the contentPath.

Example:

export const contentMap = {
    // ... existing entries
    '/content/theory/rhythm.md': `# Rhythm (Fallback)\\n\\nThis is fallback content for Rhythm.`,
};

How to Add a New Top-Level Menu Item

To add a completely new category, like "Instruments", follow these steps.

Step 1: Edit app-data.js

  1. Open app-data.js.
  2. Add a new object to the main menuItems array. A top-level item should have a children array containing its submenu items.

Example:

// ... inside the menuItems array
{
  id: 'instruments',
  label: 'Instruments',
  icon: FolderIcon, // FolderIcon is a good choice for a category
  children: [
    {
      id: 'instruments-piano',
      label: 'Piano',
      icon: MusicIcon,
      contentPath: '/content/instruments/piano.md'
    },
    {
      id: 'instruments-guitar',
      label: 'Guitar',
      icon: MusicIcon,
      contentPath: '/content/instruments/guitar.md'
    }
  ]
}

Step 2: Create Content Files

  1. Create the necessary directory structure (e.g., create an instruments folder inside content).
  2. Create the content files you defined: content/instruments/piano.md and content/instruments/guitar.md.
  3. Add content to each file.
  4. (Optional) Add fallback content for these new files in app-data.js.

How to Add a New Icon

If you want to use a new icon:

  1. Find or create an SVG for your icon.
  2. Open icons.js.
  3. Add and export a new constant containing the SVG string.

Example:

export const GuitarIcon = `<svg class="w-6 h-6" ... >...</svg>`;
  1. Import the new icon at the top of app-data.js:
import { FolderIcon, MusicIcon, GuitarIcon } from './icons.js';
  1. You can now use GuitarIcon in the icon property of your menu item objects in app-data.js.
