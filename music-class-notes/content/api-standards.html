REST & GraphQL Standards

All API endpoints must be documented using OpenAPI 3.0 specs. We follow standard HTTP status codes: 200 for success, 400 for bad requests, and 500 for server errors.

Rate limiting is enforced at 1000 req/min for all public endpoints. When designing new endpoints, prefer resource-oriented URLs (e.g., /users/123/orders).
